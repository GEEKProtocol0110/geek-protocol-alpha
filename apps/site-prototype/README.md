# Geek Protocol Site Prototype

This directory contains the complete static Site prototype imported from ChatGPT Sites version 8.

## Included

- Landing page and Kaspa information
- Playable quiz experience
- Eight question categories
- Lobby interface
- Mint interface
- GEEK Protocol artwork and visual lore

## Preview locally

Serve the `dist` directory with any static file server:

```bash
npx serve apps/site-prototype/dist
```

The prototype is intentionally isolated from `apps/web` so it can be reviewed and selectively integrated into the production Next.js application without overwriting the existing alpha.
